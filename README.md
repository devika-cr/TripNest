TripNest is a travel listing web application built using the MERN stack (MongoDB, Express, React, Node.js).
It allows users to explore various travel listings such as rooms, mountains, and iconic cities, with pricing and GST details.

🔗 Live Demo: https://tripnest-yvhb.onrender.com/listings

Features:
Displays travel listings with name, price, and category
Simple and user-friendly interface
Categorized browsing (Rooms, Mountains, Castles, etc.)
Responsive design for better mobile view

Tech Stack:
Frontend: HTML, CSS, JS
Backend: Node.js, Express.js
Database: MongoDB
Hosting: Render
